# Salon Management System

A comprehensive salon management software that helps salon owners manage their business operations efficiently.

## Features

- **Customer Management**: Maintain customer profiles, contact information, and service history
- **Appointment Booking**: Online booking system with calendar integration
- **Service Catalog**: Manage services, pricing, and categories
- **Staff Management**: Staff scheduling and service assignments
- **Payment Processing**: Integrated billing and payment management
- **Inventory Management**: Track products and supplies
- **Reporting & Analytics**: Business insights and performance metrics
- **Notifications**: Automated customer reminders and notifications

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/abponline/start.git
cd start
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:3000`

## Project Structure

```
salon-management/
├── backend/          # Node.js API server
├── frontend/         # React web application
├── shared/           # Shared utilities and types
└── docs/            # Documentation
```

## Technology Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express, SQLite
- **Authentication**: JWT
- **Database**: SQLite (development), PostgreSQL (production)
